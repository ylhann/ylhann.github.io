Confidentialité de Pip, compagnon de bureau

AppsFactory42 · 26 novembre 2026

Pip fonctionne sur votre appareil sans compte, sans publicité et sans envoyer de données à AppsFactory42. Vos réglages, les repères que vous placez et les défis accomplis sont conservés dans les données locales de l’application. Effacer ces données ou désinstaller Pip les supprime.

Pourquoi Android demande deux accès

L’affichage par-dessus les applications permet de dessiner Pip et de recevoir vos gestes dans la fenêtre du personnage. L’accès aux données d’utilisation permet de déterminer si le bureau est affiché et de masquer Pip lorsque vous ouvrez une autre application. Cette décision est traitée en mémoire. Pip ne conserve ni ne partage votre historique d’utilisation.

Vous pouvez arrêter Pip dans l’application et retirer ces accès dans les paramètres Android. Les notifications permettent aussi de retrouver la commande d’arrêt.
